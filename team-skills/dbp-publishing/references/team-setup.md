# Team setup (fill in once per language team)

| Value                | Meaning                                                            | This team |
| -------------------- | ------------------------------------------------------------------ | --------- |
| `{{CHANNELS}}`       | YouTube channel, Facebook page, Instagram account, other platforms |           |
| `{{LONG_FORM_DAYS}}` | Days a long form goes out                                          |           |
| `{{LONG_FORM_TIME}}` | Local time of the long form                                        |           |
| `{{SHORTS_TIMES}}`   | Local times for Shorts                                             |           |
| `{{PLAYLIST}}`       | YouTube playlist for long forms                                    |           |
| `{{UTM_CAMPAIGN}}`   | e.g. `daily_bible_pause_ru`                                        |           |
| `{{CALENDAR}}`       | Link to the shared story calendar                                  |           |
| `{{LANGUAGE}}`       | Video language setting on YouTube                                  |           |

The team agent uses its own logins to the platforms. It never signs in for anyone, never types passwords, and never changes account or page settings.
