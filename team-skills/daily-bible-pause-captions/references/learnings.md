## Standing preferences

Things the user has decided that aren't up for re-litigation each session. Add to this as it becomes clear.

- Instagram Reels is the default platform; Facebook adapted on request.
- A YouTube package — title, three cover-text options, description — ships with every session without being asked for.
- YouTube Shorts description by default; long-form description only when the video is clearly long-form.
- Cover/thumbnail text is capped at six words.
- English by default; Russian versions on request.
- Captions should be ready to paste — no labels or commentary inside the caption body.
- YouTube title format: `<title> | <passage>`.
- Every YouTube long-form package includes a pinned comment (Shorts: none): since Oct 28, 2026 a link to the episode's scene on jesusfilm.org with UTM. History: personal questions (0 replies under 14 videos) → a prayer + "Pray it with us and write Amen" (Oct 19) → the prayer alone (Oct 21) → the scene link (Oct 28).
- No AI disclaimer line in captions or descriptions (owner, Oct 23, 2026). Credits only: film, translation, reflection author with year.
- No em or en dashes in any copy that gets published (they read as AI-written). Use a colon, a full stop or a comma instead.
