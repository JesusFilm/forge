# Simple captions file (for a person to copy from)

One file per video, `captions_<story>.txt`, in this order and nothing else:

1. Title line (short name + passage) and one note that the same text works for Instagram, Facebook and the YouTube description.
2. Options 1, 2, 3: caption text only; mark one "(recommended)". For Shorts that do not say "Watch the full devotional" on screen, name the full devotional in the first or second line.
3. HASHTAGS: one set for all.
4. YOUTUBE TITLE: 2–3 options, `<title> | <passage>` (long forms: the search rules).
5. CREDITS: once.
6. PINNED COMMENT (long forms only): the scene link line.

No Purpose / Test / Keep Constant lines, no per-platform variants, no log entry.
