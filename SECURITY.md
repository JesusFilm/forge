# Security Policy

## Supported Versions

| Component          | Supported |
| ------------------ | --------- |
| `main` branch      | Yes       |
| Latest release tag | Yes       |
| Older releases     | No        |

## Reporting a Vulnerability

**Do not open a public issue** for security vulnerabilities.

1. **Report** via [GitHub Security Advisories](https://github.com/JesusFilm/forge/security/advisories/new) with:
   - Description of the vulnerability
   - Steps to reproduce
   - Impact assessment
   - Suggested fix (if any)

2. **Expect**:
   - Acknowledgment within 48 hours
   - Initial assessment within 7 days
   - Updates as we triage and fix

3. **Scope**:
   - `apps/web`, `apps/cms`, `apps/mobile`
   - `packages/graphql`, `apps/cms/schema.graphql`

4. **Out of scope**:
   - Third-party dependencies (report upstream)
   - Social engineering, physical access, denial-of-service
   - Issues in unsupported versions

We appreciate responsible disclosure. We will credit reporters (with permission) when the issue is resolved.
