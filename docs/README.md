# docs

Operational and architecture docs.

- `architecture/`: system diagrams, lifecycle and design decisions.
- `runbooks/`: operational procedures and guardrails.
- `index.md`: generated catalog of migrated artifacts.
- `migration-manifest.json`: deterministic migration state.
- `issues/`: normalized migrated issue artifacts.
- `plans/`: normalized migrated plan artifacts.
- `templates/`: canonical markdown templates used by migration.
