# Generated catalog identities and immutable staged releases

A generated render has Forge Video, locale, Dub, Edition and Mux identities with
MANAGER ownership. Its missing Core identity is null, never a fabricated Core ID.
Migration `0079_studio_catalog_identity` preserves the existing unique indexes and
requires nonblank real Core IDs for CORE Video/Dub/Edition rows. Historical
MANAGER rows may retain real Core IDs; ownership, not nullability, controls sync.

`StudioCatalogService.stage` accepts only a trusted service principal. The shared
`@forge/studio-contracts/catalog` manifest binds a successful render attempt to
its exact project revision, input hash, runtime, language, dimensions, timing and
registered output digest. Both retained report and output bytes are hash-read.
The report is renderer-supplied metadata: **feat-460 must produce and verify actual
render codec/dimension evidence and signed Mux readiness**. A JSON declaration or
455 source descriptor is not that proof. Registration makes no provider calls.
Mux IDs cannot alias an existing catalog identity; advisory locks serialize
competing Studio projects using the same external IDs.

The transaction locks the project, resolves the existing 455 source/pack registry,
requires materialized source coverage, rechecks current eligibility, and carries
the union of current platform restrictions into the generated Video. Do not copy
only snapshot restrictions. Source snapshots retain exact Video/Dub/Edition,
language slug, subtitle track and selected media/version identities. Derivations
pin each timeline item's exact source range and frame placement; pack references
pin immutable revisions. The release snapshot also retains the document, report,
assets and generation metadata. This is separate from mutable draft revisions.

Retries with the same project/idempotency key and payload return the same release,
including after draft edits; conflicting payloads fail. A render can be registered
once. All five catalog records and the release are created atomically. Locale is
DRAFT, dub unpublished/non-downloadable, Video no-index, and no public HLS is set.
Database guards freeze release content and reject attaching additional locales or
dubs, including by moving an existing record. Public Video/Dub lookups also exclude
Studio releases explicitly because those legacy roots do not otherwise require a
published locale. Merely completing Mux/render work cannot make content public.

## Publication handoff

Feat-460 must add its dedicated transaction-bound visibility transition to the
catalog freeze trigger and the public release predicate. Revalidate current source
eligibility there; do not weaken the immutable document/evidence boundary. Keep
human approval, signed Mux verification and current restrictions mandatory. This
slice deliberately exposes no publication command. `createStudioCatalogAdapter`
in Manager is the typed server transport for staging/reading releases.

## Consumer and sync audit

- Admin GraphQL Video, VideoDub, VideoEdition and Watch feed/inventory DTOs expose
  nullable Core IDs. SDL and gql.tada introspection are generated by scripts.
- Mapper's legacy Core-only protocol filters missing Video/Dub Core identities
  **before pagination**, preserving Core tombstones and cursor behavior.
- Edition, Dub and Mux conflict updates protect MANAGER ownership. Existing
  incomplete-page suppression and CORE-only tombstones are unchanged. Maps for
  Core downloads/images/subtitles exclude absent real IDs explicitly.
- Manager's legacy enrichment/automation/Smart Crop paths require real Core IDs.
  Studio uses its catalog adapter. Never substitute a Forge ID into a Core field.
- Watch general cards use Forge document identity and preserve null Core fields;
  curated Core collections remain Core-only. No added fetches, hydration effects,
  media initialization or cache changes; nullable normalization adds no loading work.
- Mobile/TV use shared generated clients and Forge playback identity. Their curated
  home/experience lists remain explicitly Core-only; no mobile/TV UI release is added.
- Transcript/Mastra legacy ingestion and backfill maps remain Core-only; Typesense
  already supports absent Core identity. The execution plan records exact paths.

rejected null Manager IDs; ingest initially leaked through direct Video lookup;

apply from empty. Studio service suites pass 28 cases, including 132 preserved

GraphQL authorization and mapper tombstones. The separate real Core-sync case
checks ownership protection and existing tombstone behavior. Fixture video bytes
exercise storage and metadata contracts, not actual codec certification.
