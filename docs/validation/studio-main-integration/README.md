## Isolation and limitations

All test/build execution used an owned user/network namespace with private loopback and no external route, explicit guards against default 5432/6379, no dotenv overlays, synthetic local configuration and telemetry disabled. Migration fixtures used owned port 55463. Native tests retain their historical hardcoded endpoint guards, so the same owned cluster was bound to 55458/55461 **inside the private namespace**, with owned test database names. These are not shared host endpoints. Runtime harnesses are recorded, not portable infrastructure provisioning scripts; their paths are intentionally task-owned. Fixture production/publication flags only admit local synthetic test commands and do not change source/deployed controls.

Retained unsuccessful runs are explicitly qualified:

- `install.log`: missing frozen offline tarball, resolved by authorized registry fetch without dependency drift.
- `posters-red.log`: genuine semantic integration defect, fixed and green.
- `transcript-studio-initial.log`: incorrect test expectation of Studio ingestion success; the existing Core-only denial was correct, not a product exposure.
- `transcript-studio-boundary.log`: wrong fixture method name, corrected to the existing command service.
- `native-calendar-compat.log`: two skipped tests because the harness lacked the calendar-specific opt-in; `native-calendar-green.log` records the two actual passes.
- `admin-build.log`: Google Fonts unavailable in the isolated namespace. The passing retry substitutes a declared CSS response fixture using local Arial, not downloaded production font bytes.
- `web-build.log`: compilation and types passed, then page-data collection rejected three missing fixture configuration variables. The retry supplies dummy revalidation/API values and a private loopback Admin URL, without bypassing validation.
- `loading-fixture.log`: Chromium's singleton socket path exceeded the Unix path limit. The passing retry uses a short owned rootfs TMPDIR. Browser `--no-sandbox` is a local test-launch setting, not renderer containment evidence.
