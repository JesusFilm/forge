# CLAUDE.md — RAG Roadmap Lane

This is a docs-only, hand-maintained lane for the migration programme rooted at
[`JesusFilm/jesusfilm-rag#130`](https://github.com/JesusFilm/jesusfilm-rag/issues/130).
It is deliberately absent from `apps/roadmap/lib/features.ts` `LANE_DIRS`, both
`README_LANE_ORDER` lists, and generated root roadmap totals. Do not register it.

Follow the root roadmap format. IDs are globally allocated. Keep dependencies
bidirectional within this lane. Update this folder's `README.md` whenever ticket
status, dependencies, or PR links change. Once this programme exists in Forge,
future RAG work is created here rather than as new standalone-repository issues.

Status reflects what will land with the current Forge PR. A completed ticket
must gain a `## Resolution` section with the Forge PR link before merge.
