# Plan Artifact: #77

## Objective

A concise runbook covering web deployment lifecycle: preview validation, stage acceptance, production promotion, rollback, and incident handling.

## Planned approach

1. Single markdown guide under docs with sections per environment.
2. Include minimal command/API snippets for diagnostics.
3. Link to CMS dependency assumptions (endpoint/token contract).

## Validation

- [ ] Runbook documents PR preview validation checklist.
- [ ] Stage verification checklist is explicit (content fetch, preview mode, revalidate endpoint behavior).
- [ ] Production promotion checklist is explicit and approval-aware.
- [ ] Rollback procedure for Vercel deployment and alias recovery is documented.
- [ ] Troubleshooting section includes common failure signatures and first-response steps.
