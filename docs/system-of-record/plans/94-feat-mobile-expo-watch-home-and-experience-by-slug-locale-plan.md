# Plan Artifact: #94

## Objective

- Watch home screen: fetches homepage experience for a locale and renders all section types via section renderers.
- Experience-by-slug screen: fetches experience by slug and locale; renders sections including nested Section/Container wrappers.
- Navigation/routing so users can open home and slug-based experiences (e.g. deep link or tab/stack).
- Locale supported (passed to data layer).

## Planned approach

1. Expo Router or React Navigation; routes like `/` (home) and `/[slug]` or `/[slug]/[locale]`.
2. Data layer called from screen/hook; section list passed to SectionDispatcher loop.

## Validation

- [ ] Watch home screen implemented and shows section-based content for all 10 active section types.
- [ ] At least one experience-by-slug route (e.g. easter or christmas) with locale.
- [ ] Navigation between home and slug experiences (e.g. React Navigation or Expo Router).
- [ ] Nested Section and Container content renders correctly within experience screens.
- [ ] Loading and error states handled.
