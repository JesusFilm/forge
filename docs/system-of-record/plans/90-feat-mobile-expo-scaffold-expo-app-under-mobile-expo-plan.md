# Plan Artifact: #90

## Objective

- A new Expo (React Native) project under `mobile/expo` that builds and runs on iOS and Android.
- TypeScript enabled; folder structure organized by feature (not only by type).
- Minimal runnable app (e.g. default Expo template) with no shared business logic with `mobile/ios` or `mobile/android`.

## Planned approach

1. Use `npx create-expo-app` with TypeScript template; move/copy into `mobile/expo` and adjust package name if needed.
2. Ensure monorepo compatibility (workspace root may need to reference the new app for lint/turbo if desired in a later issue).

## Validation

- [ ] Expo app created under `mobile/expo` (e.g. via `npx create-expo-app` or equivalent).
- [ ] App runs on iOS and Android (simulator/emulator or device).
- [ ] TypeScript configured.
- [ ] Folder structure by feature (e.g. `features/`, `screens/`, or equivalent) documented or evident.
- [ ] No dependency on native app code (#80); this is the Expo surface only.
