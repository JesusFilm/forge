# Languages below recommendation coverage requirements

**Video availability clarification:** [fresh Core `videoVariants` checks](video-variants-cross-check.md)
found 48–568 videos with playback data in every one of the 200 translation-blocked
languages below. These are card-eligibility gaps. Persian Sign Language also has
additional declared streams, but 61 chapter links failed live redirect checks.
The tables retain the original local eligibility counts, not a fresh global
claim that these languages lack videos.

This list concerns the new **Recommended for You** row under the homepage’s default language mapping. It is based on the restored local catalog audited on 10 September 2026; it is not a claim that the whole video library is unavailable or that current production has been checked.

**236 language contexts cannot supply six eligible curated cards. Another eight can supply six but do not meet the planned thirty-video reserve.** Language names below come from the local Admin catalog; exact audio slugs preserve regional and sign-language distinctions.

A missing card translation can block recommendations even when the audio dub exists. Chinese cases include both absent generic `zh` display rows and mismatched `zh-Hans`/`zh-hans`, `zh-Hant`/`zh-hant` keys. The inventory ceiling includes uncurated Admin IDs before canonical deduplication.

Source: [complete homepage matrix](all-context-web-default-coverage.csv). Background and validation: [coverage report](all-context-coverage-report.md). Machine-readable filtered list: [unavailable-homepage-languages.csv](unavailable-homepage-languages.csv).
