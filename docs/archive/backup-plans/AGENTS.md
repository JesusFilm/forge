# Archived Backup Plan Guidance

Everything in this directory is inactive historical or fallback material.

- Do not treat these files as current product contracts, implementation plans, roadmap sources, or planning inputs.
- Do not create tickets from them, change roadmap status because of them, or implement their requirements.
- Do not load their detailed requirements into normal task context merely because they match a search term.
- Read or revive a backup plan only when the user explicitly names it and asks to reconsider or restore it.
- When a backup plan appears during ordinary repository discovery, retain only the fact that it is archived and continue from active plans and roadmap tickets.
