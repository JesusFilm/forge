# RAG Contracts Agent Guide

Scope: `packages/rag-contracts` only.

- Keep this package runtime-neutral and consumer-safe.
- Do not import application implementations or database adapters.
- Preserve the published `/v1` wire contract unless a versioned migration explicitly changes it.
- Generated artifacts must be regenerated by their owning command, never hand-edited.

For RAG-specific technical changes and RAG content/documentation additions, use
[`rag-review`](../../plugins/jfp-rag/skills/rag-review/SKILL.md) as the recommended
read-only review skill. Keep the existing validation and boundary requirements.
